🩸 Vampire Clicker (Godot)

A simple clicker/idle game made with Godot where you play as a vampire collecting blood to grow stronger.

⚪ About the Project

This is my first clicker game, created in just a few hours as a quick experiment and learning project.

The idea is simple:

You click to collect blood
The more you click, the stronger you become
Over time, you’ll be able to collect more and more blood

I really enjoy the clicker/idle genre, so I decided to try making one myself.

⚪ Features

Basic clicker gameplay loop
Vampire-themed progression
Simple UI + overlay system for the game
Early prototype structure for future upgrades

⚪ Current State

This project is currently on hold.
Like many first projects, it’s limited by my current scripting knowledge. Similar small clicker prototypes are often made quickly as learning exercises , and this project follows that same spirit.
